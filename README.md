# RandomUtil

一个 Minecraft 1.7.10 / Forge 工具模组。提供一组零碎但实用的小功能，当前包含一个神秘时代研究查询功能。

## 功能

| 功能             | 说明                                                            |
|------------------|-----------------------------------------------------------------|
| 神秘时代研究查询 | 查询自己或他人还缺哪些研究，支持章节、分页、过滤、导出          |

## 神秘时代研究查询

```
/ru                                 列出所有子命令
/ru thaum research <章节|all> [玩家]
```

`thaum` 也可以写成 `thaumcraft` 或 `tc`。

不写玩家时查询自己；写其他玩家名时通过服务端查询。

### 选项

| 选项 | 说明 |
| --- | --- |
| `--hidden` | 同时列出研究书里看不见的节点（隐藏 / 失落 / 未满足条件的暗藏节点） |
| `--avail` | 只列出前置条件已满足、马上可以研究的节点 |
| `--page=N` | 分页，默认 `N=1` |
| `--limit=N` | 每页条数，默认 `8`，上限 `50` |
| `--raw` | 只输出研究 key，空格分隔，方便复制 |
| `--count` | 只输出汇总数字 |
| `--dump` | 结果写入 `logs/randomutil-<玩家>-<章节>.txt` |
| `--help` | 显示帮助 |

### 章节

支持 `all`、章节 key（`ALCHEMY`）、当前语言的章节名（`炼金术` / `Alchemy`），以及简写别名（`炼金`、`thaumaturgy` 等）。装了 addon 章节会自动出现。

### 输出示例

```
[RandomUtil] Steve @ 全部章节
未解锁 42/179，已完成 137
BASICS 基本信息 - 0/28 可研究 0
ALCHEMY 炼金术 - 7/42 可研究 2
...
现在可研究 (2)
 + [NITOR] 炽心
 + [TALLOWCANDLE] 脂烛
隐藏或未发现: 12 (加 --hidden 查看)
```

### 查询他人

Thaumcraft 只把本地玩家的研究数据同步到客户端，所以查别人必须由服务端计算。服务端装了本模组时，客户端发请求、服务端算好结果再发回来；服务端没装时 3 秒后提示查询失败，查自己不受影响。单机 / 局域网会自动使用内置服务端，无需额外配置。

服务端配置（`config/randomutil.cfg`）：

| 分类      | 配置项                | 默认    | 说明                           |
|-----------|-----------------------|---------|--------------------------------|
| `general` | `debug`               | `false` | 输出额外诊断日志               |
| `thaum`   | `enableQuery`         | `true`  | 是否允许客户端发起研究查询     |
| `thaum`   | `allowQueryOthers`    | `true`  | 是否允许查询其他玩家           |
| `thaum`   | `allowOfflineQuery`   | `false` | 是否允许读存档文件查询离线玩家 |
| `thaum`   | `requireOpForOffline` | `true`  | 查询离线玩家是否要求权限等级 2 |
